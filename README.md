# 文档小站 V1.4

在 V1.3 的基础上增加转换页码范围、JPG 导出和图片清晰度选择；所有操作均在浏览器本地完成。

## 本次升级

- PDF → DOCX：可编辑文字模式提取文本并按行排版；保留外观模式将 PDF 页面图片放入 Word。
- PDF → PPTX：每页生成一张图片幻灯片，支持扫描件；文字不能单独编辑。
- PDF → TXT：UTF-8 编码，保留分页标记；纯扫描件会明确报错，混合文档会提示未提取到文字的页。
- 每项功能都有独立的「下载文件」按钮，转换成功后才启用。不会自动弹出下载。
- PDF → PNG 改为 ZIP 一次下载，避免浏览器拦截连续下载。
- PDF → JPG / PNG：可选格式、标准 1× / 清晰 1.5× / 高清 2×，多个选定页面打包 ZIP；JPG 适合减小文件，PNG 适合无损保存。
- PDF → DOCX / PPTX / TXT / 图片均可填写页码范围，如 `1,3,5-8`；留空处理全部页面。TXT 中保留 PDF 原页码。
- 更换文件、模式或页码会清除旧下载；运行期间锁定该任务控件，防止重复执行。
- 页码严格校验，错误或超范围页码会提示。保留原有合并、拆分、旋转、图片转 PDF。
- 当前公网部署版通过固定版本 CDN 加载转换组件；文件内容仍只在浏览器本地处理，不上传转换服务器。

## 部署或更新

公网部署保持 index.html、app.js 和 vercel.json 在网站根目录即可；转换组件使用固定版本 CDN。原始完整包仍保留 vendor/，适合需要完全本地依赖的离线/自托管部署。

本地预览：在此目录运行 `python3 -m http.server 8000`，浏览器打开 http://localhost:8000。请勿直接双击 HTML，以免浏览器阻止模块和 Worker。网站未自动部署。

## 转换范围

可编辑 DOCX 是文字提取版，不是高保真排版重建；图片、表格结构、多栏顺序、公式格式不能保证恢复。重要中文、表格或公式资料优先选择保留外观模式，并核对原件。保留外观模式的文字不可单独编辑，不包含 OCR。

Word / PPT / Excel → PDF 尚未提供。本次不新增服务器，后续需要独立转换后端才能实现这些高保真功能。

单次输入总计最多 50 MB；基于 PDF.js 的转换最多 100 页；图片结果总量最多 100 MB。低内存手机可先拆分再转换。加密文件请先解锁。

页面渲染使用白色背景，最大约 6 百万像素、最长边 4096 像素。超长页面会降低分辨率。图片清晰度选择只作用于图片导出；DOCX 外观模式和 PPTX 固定使用高清渲染。PPTX 以所选第一页比例为统一画布，其余页面按比例居中。

PDF 已有文字层但识别错误时，可编辑 DOCX / TXT 会继承原件中的错字。公式、上下标、表格与复杂排版应对照 PDF 核查；需要一模一样的页面请选择 Word 外观模式。

## 隐私

文件内容不会上传，也不会写入服务器。结果保留在当前页面内存中，离开页面即释放。文件内容不会发送到 CDN；CDN 仅用于加载固定版本的前端转换库。
