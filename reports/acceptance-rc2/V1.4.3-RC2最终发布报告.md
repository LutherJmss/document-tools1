1. 四平台实机缺少机型、系统/App 版本、原生截图及逐项判定，是明确未完成的验收门槛。

4. 真正教材的原生公式/OCR 修复均为 0；36 用例的策略通过率不能替代数学 OCR 成功率。
5. 性能与体积增加约 9.8%，没有低端手机和真实网络耗时数据。
6. GitHub remote/main/CI 不可见；本地提交成功不等于 GitHub 已提交或可合并。
